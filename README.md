# 99quest たいけんばん

1・2の段を遊べる九九RPG。最初だけ先生が4桁PINを決め、そのあと子どもが仲間を選びます。

- しきの左から数字を打ちます。例: 2×2=4 は 2 → 2 → 4。
- Enterを少し長く押すと答えを確定し、次の問題へ進みます。問題ごとの開始・次へ操作は不要です。Enterは一度離してから次の答えを確定します。Backspaceで消せます。
- 「すうじキー」で画面の数字ボタンを表示できます。
- 「おと ON/OFF」でBGM・効果音を切り替えます。Escape/「ひとやすみ」で中断できます。
- 順番 → ばらばら → ボス。さらに9つの式をばらばら・練習で各2回自力正解すると次の世界が開きます。
- 先生画面ではPINを入力して世界2を開けることもできます。

同じURLを各自の端末で開いて遊べます。アカウント登録はありません。記録はその端末・ブラウザだけに保存され、送信されません。同じ端末・同じブラウザを交代で使う場合は同じ記録になります。

ブラウザのデータを消すと記録が失われる可能性があるので、必要に応じて先生画面から記録ファイルを保存してください。学習記録は児童間で共有しません。

`index.html`を保存して直接開くと、通信せずに遊べます。URL版とファイル版は保存場所が異なるため、切り替える場合は先生画面の記録ファイルで引き継ぎます。
